# Screen Text Dubbing Tool — Deployment Guide / 部署说明

## 环境要求

| 组件 | 版本要求 | 用途 |
|------|---------|------|
| Python | 3.10+ (推荐 3.11+) | 主运行环境 |
| Tesseract OCR | 5.x | 屏幕文字识别 |
| Git | 任意 | 克隆仓库（可选） |
| 操作系统 | Windows 10/11 | 全局热键和输入监控 |

## 快速部署

### 1. 获取代码

```powershell
git clone https://github.com/koshistar/TextDubbingTool.git ScreenTextDubbingTool
cd ScreenTextDubbingTool
```

### 2. 创建虚拟环境

```powershell
python -m venv .venv
.\.venv\Scripts\activate
```

### 3. 安装依赖

```powershell
pip install -r requirements.txt
```

> 若 `pyaudio` 安装失败，请从 [这里](https://www.lfd.uci.edu/~gohlke/pythonlibs/#pyaudio) 下载对应 Python 版本的 `.whl` 手动安装。

### 4. 安装 Tesseract OCR

1. 从 [UB-Mannheim/tesseract](https://github.com/UB-Mannheim/tesseract/wiki) 下载 Windows 安装包
2. 安装时勾选中文语言包 `Chinese (Simplified)`
3. 记下安装路径（如 `C:/Program Files/Tesseract-OCR/tesseract.exe`）

### 5. 配置

```powershell
# 复制配置文件模板
copy config.yaml.example config.yaml
copy .env.example .env
```

编辑 `config.yaml`，填入你的 API 密钥：

```yaml
tts:
  qwen3:
    api_key: "sk-..."        # 阿里云 DashScope
  emotion_tts:
    api_token: "sk-..."      # EmotionTTS 平台

screen_capture:
  tesseract_path: "你的tesseract路径/tesseract.exe"

ai_companion:
  enabled: true
  api_key: "sk-..."          # DeepSeek / OpenAI
```

### 6. 启动

```powershell
cd path
python main.py
```

### 7. (可选) 启动 VITS 本地服务

如果使用 VITS 引擎，需先启动 [vits-simple-api](https://github.com/Artrajz/vits-simple-api)：

```powershell
cd path\vits-simple-api
python app.py
```

默认地址 `http://localhost:23456`，可在 `config.yaml` 的 `tts.vits.api_url` 中修改。

## 常见问题

### Tesseract OCR 不可用
确保 `config.yaml` 中 `screen_capture.tesseract_path` 指向正确的 `tesseract.exe`。若 Tesseract 安装在默认位置，路径通常为 `C:/Program Files/Tesseract-OCR/tesseract.exe`。

### PyAudio 安装失败
Windows 上 PyAudio 需要编译 C 扩展。替代方案：
```powershell
pip install pipwin
pipwin install pyaudio
```
或不使用实时流式播放（系统会自动降级为文件播放模式）。

### 音频设备不可用
确保系统音频设备正常工作。错误 `[Errno -9985] Device unavailable` 通常表示音频设备被其他程序占用。

### config.yaml 中的密钥安全
`config.yaml` 包含 API 密钥，已被 `.gitignore` 排除。请勿将其提交到公开仓库。
